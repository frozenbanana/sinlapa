SINLAPA – ADMIN, FORMULÄR & PAKET
=================================

Lokalt
------
1. cp .env.example .dev.vars
2. Sätt ADMIN_PASSWORD, NOTIFY_EMAIL och (för skarp mail) RESEND_API_KEY
3. npm install
4. npm run dev
5. Öppna http://localhost:8788/
   Admin: http://localhost:8788/admin/
   Offert: http://localhost:8788/erbjudande

Miljövariabler (.dev.vars / Pages Secrets)
------------------------------------------
NOTIFY_EMAIL=info@sinlapa.se
FROM_EMAIL=Sinlapa Webb <onboarding@resend.dev>
RESEND_API_KEY=re_xxx
ADMIN_PASSWORD=välj-ett-starkt-lösen

Utan RESEND_API_KEY loggas mail lokalt (formulären svarar ändå OK i dev).

Cloudflare Pages
----------------
1. Skapa KV-namespace, t.ex. sinlapa-site-config
2. Skapa R2-bucket, t.ex. sinlapa-media
3. Lägg in KV-id:n i wrangler.toml och behåll MEDIA-bindingen
4. Bind SITE_CONFIG (KV) och MEDIA (R2) i Pages-projektet
5. Sätt secrets ovan i Pages → Settings → Variables and Secrets
6. Deploy: npm run deploy

Bilder
------
Admin → fliken Bilder, eller "Välj / ladda upp" på en lunchrätt.
Uppladdningar sparas i R2 och serveras via /media/...
Befintliga webbplatsbilder finns också valbara i galleriet.
