# Arkiv: gamla sinlapa.se (WordPress)

Ögonblicksbild av den tidigare WordPress-webbplatsen, tagen 2026-08-04.
Sparas som referens inför/under migreringen till den nya sidan.

Klient hemligheten hålls utanför: inga bildfiler (foton finns redan i `public/assets` på den nya sidan),
inga externa resurser (Google Fonts m.m.), endast sidornas HTML + dess stilmallar från sinlapa.se.
Bilder i sidorna refererar fortfarande till den gamla domänen och laddar inte efter att sinlapa.se bytt till den nya sidan.
